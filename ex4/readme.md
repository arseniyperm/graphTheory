
***Венгерский алгоритм нахождения минимального по весу полного паросочетания на графе (для двудольного графа).***

**Пример:**
*Ввод:*  
[3, 14, 5, 6, 7],  
[1, 9, 7, 4, 3],  
[8, 7, 4, 6, 3],  
[5, 6, 9, 13, 15],  
[19, 14, 16, 8, 12]  
  
*Вывод:*  
Минимальный вес: 23  
Row 1 - Col 0 (1)  
Row 3 - Col 1 (6)  
Row 0 - Col 2 (5)  
Row 4 - Col 3 (8)  
Row 2 - Col 4 (3)
